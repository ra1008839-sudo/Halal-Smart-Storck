## Getting Started

Navigate to the Flutter app directory and follow the setup instructions:

```bash
cd flutter_app
flutter pub get
flutter run
```

For detailed setup instructions, see [flutter_app/README.md](flutter_app/README.md).

## Features Implemented

✅ **Core Architecture**
- Clean architecture with proper separation
- Complete project structure
- Configuration management

✅ **UI/UX**
- Groww-style dark theme
- 5-tab bottom navigation
- Stock cards and FII/DII banner

✅ **Algo Trading**
- Trading bot engine
- Risk management (Max 2% loss)
- Trailing stop loss

✅ **Technical Indicators**
- RSI, MACD, Bollinger Bands
- More indicators planned

✅ **Data**
- 500+ Halal stocks database
- Stock, User, Order models
